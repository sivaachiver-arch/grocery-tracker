🛒 Personal Grocery & Shopping Tracker

A simple and user-friendly web application to manage grocery and shopping items.

✨ Features

- ➕ Add grocery and shopping items
- ✏️ Edit and update items
- 🗑️ Delete items
- 🟢 Mark items as Purchased
- 🔴 Mark items as Pending
- 🔍 Search items
- 🏷️ Filter items by category
- 📊 Dashboard with total items, quantity, and amount
- 💾 Data persistence using Browser LocalStorage
- 📱 Responsive design for mobile and desktop

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

📂 Project Structure

grocery-tracker/

▶️ How to Run

Clone the repository:

git clone https://github.com/sivaachiver-arch/grocery-tracker.git

Go to the project folder:

cd grocery-tracker

Start a local web server:

python3 -m http.server 8000

Open the application in your browser:

http://127.0.0.1:8000
